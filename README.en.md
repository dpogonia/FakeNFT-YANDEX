# FakeNFT

An NFT catalog for iPhone. A Yandex Practicum study project. Purchases go through the course server.

Design: [Figma](https://www.figma.com/design/Uz5G39wRRCr2mRE4SbnNla/FakeNFT--YP-). Course starter: [iOS-FakeNFT-StarterProject-Public](https://github.com/kit10000000/iOS-FakeNFT-StarterProject-Public).

## What it does

Two tabs: the catalog and the cart.

The catalog lists collections. A collection opens the works, the author's page, and an NFT card.

In the cart you can remove an item and pay with a chosen currency. A result screen follows the payment.

The screens are built in code, using MVP.

## Stack

UIKit, Kingfisher, ProgressHUD, URLSession.

## Run

```bash
git clone https://github.com/dpogonia/FakeNFT-Yandex.git
cd FakeNFT-Yandex
open FakeNFT.xcodeproj
```

Run the **FakeNFT** scheme on an iPhone simulator.
