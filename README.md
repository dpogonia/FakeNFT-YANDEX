# FakeNFT

Каталог NFT для iPhone. Учебный проект Яндекс Практикума. Покупка идёт через учебный сервер.

Макет: [Figma](https://www.figma.com/design/Uz5G39wRRCr2mRE4SbnNla/FakeNFT--YP-). Стартовый репозиторий курса: [iOS-FakeNFT-StarterProject-Public](https://github.com/kit10000000/iOS-FakeNFT-StarterProject-Public).

## Что умеет приложение

Две вкладки: каталог и корзина.

В каталоге список коллекций. Коллекция открывает работы, страницу автора и карточку NFT.

В корзине позицию можно удалить и оплатить выбранной валютой. После оплаты показывается результат.

Экраны собраны кодом, по MVP.

## Стек

UIKit, Kingfisher, ProgressHUD, URLSession.

## Запуск

```bash
git clone https://github.com/dpogonia/FakeNFT-YANDEX.git
cd FakeNFT-YANDEX
open FakeNFT.xcodeproj
```

Запустите схему **FakeNFT** на симуляторе iPhone.
